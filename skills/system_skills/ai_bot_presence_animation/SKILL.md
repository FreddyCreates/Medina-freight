## 1. Core Visual Archetypes

### Archetype A: Grokbot 3D Gyroscopic Singularity & DALL-E Generative Iris
- **Form Factor**: Sleek floating metallic robotic head (`rounded-[22px]`) with vertical anti-gravity hover oscillation (`@keyframes grokbotHover`) and dynamic ground shadow scaling.
- **Magnetic Ear Pods**: Left & right floating sensor pods with glowing multi-channel audio LED halos.
- **Top Antenna Beacon**: Micro-sensor pin indicating active network ping.
- **Curved Obsidian Visor**: Dark obsidian glass screen (`#09090B`) with realistic optical specular reflection gloss (`from-white/25 via-white/5 to-transparent`).
- **Expressive Robot Visor**:
  - `idle`: Twin digital glowing robotic eyes blinking at 4-second intervals (`@keyframes grokEyeBlink`).
  - `listening`: Multi-bar audio frequency equalizer dancing dynamically (`@keyframes equalizerBar`).
  - `thinking` (Document OCR / Vision Photo processing): DALL-E 6-blade camera aperture iris spinning 360°, rotating conic radar laser sweep (`@keyframes dalleLaserSweep`), and a glowing horizontal document OCR scanner bar sweeping vertically across paperwork (`@keyframes dalleScanLine`).
  - `executing`: Determined quantum surge arc with bouncing energy glyph.
  - `done`: Friendly smiling crescent eyes (`^ ^`) with confirmation check badge.
- **3D Orbital Gimbals**:
  - Ring 1 (Planetary): `rotateX(66deg) rotateY(-20deg)` with a high-contrast tracking photon node (`@keyframes grokSpin3D1`).
  - Ring 2 (Polar Counter-Axis): `rotateX(-35deg) rotateY(55deg)` with counter-orbital satellite node (`@keyframes grokSpin3D2`).
  - Ring 3 (Equatorial): Dashed metallic horizon ring with precision equatorial spin (`@keyframes grokSpinEquator`).
  - Acoustic Waveform Emitters: Multi-layer 3D harmonic ripple rings expanding spherically during voice and vision states (`@keyframes acousticRipple3D`).

### Archetype B: OpenAI Voice Dot & Fluid Dynamic Neural Core
- **Form Factor**: Multi-point organic liquid morphing core (`fluidOrganicMorph`) with shifting internal gradient layers.
- **Acoustic Halo**: Ethereal chromatic edge diffraction and harmonic sound pulse rings.
- **Orbital Photon**: Smoothly orbiting satellite beacon tracing the perimeter.

### Archetype C: Quantum Singularity & Gravitational Lensing
- **Form Factor**: Relativistic event horizon sphere with high-speed spinning particle accretion disk, 3D gravitational lensing rings, and magnetic pulsar bursts.

### Archetype D: Cybernetic Sentinel & Matrix Oscilloscope
- **Form Factor**: Futuristic cybernetic HUD visor with dual telemetry antennas, dynamic matrix oscilloscope waveform bars, and laser targeting scan line.

## 2. Essential CSS Keyframes Specification

@keyframes grokbotHover {

  }

  }
  75% {
    transform: translateY(-2px) rotate(0.5deg);
  }

    transform: scale(1);
    opacity: 0.45;
  }

  }

    transform: rotateX(-35deg) rotateY(55deg) rotateZ(360deg);
